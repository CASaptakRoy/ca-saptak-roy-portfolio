# CA Saptak Roy Portfolio — V3

## What is editable?
Everything in `index.html` is editable. You can change:
- name/headline
- recruiter summary
- experience bullets
- impact statements
- case studies
- qualifications
- awards
- AI/technology tags
- email/phone/LinkedIn links
- colors, spacing and fonts in the CSS

## Easiest workflow
Upload the files to a GitHub repository and enable GitHub Pages. Then use GitHub's Edit (pencil) button on `index.html`, make a change, and commit it.

## If you want me to change it
Send plain instructions such as:
- “Change the headline.”
- “Make it navy and gold.”
- “Add my photo.”
- “Remove marks/percentages.”
- “Add another project.”
- “Make it more corporate.”
- “Make it more futuristic.”
I can regenerate the package.

## Publishing
1. Create a GitHub repository.
2. Upload `index.html` and `CA-Saptak-Roy-Resume.pdf`.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select the main branch and root folder.
5. Save. GitHub provides the live URL.

Keep the PDF filename the same if you want the Download CV buttons to continue working.
